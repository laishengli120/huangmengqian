# 黄梦芊的放映室

一个本地运行的 3D 视频放映室页面。页面使用 Three.js 构建立体放映场景，并提供视频选择、播放和沉浸式观看体验。

## 功能

- 本地浏览器直接运行
- 3D 放映室视觉效果
- 支持选择本地视频文件
- 可隐藏或显示控制面板
- 适合个人展示、演示页面或本地视频播放实验

## 技术栈

- 原生 HTML / CSS / JavaScript
- Three.js r128
- 浏览器 File API

## 使用方法

直接打开 `index.html`，在页面控制面板中选择本地视频文件即可播放。视频文件不会上传到服务器，浏览器只在本地读取。

## 项目结构
